# TOEIC 単語学習アプリ 仕様書（v0.2）

## 1. 目的
- TOEIC **730点前後** の取得に必要なビジネス語彙を、スマホで毎日少しずつ学習する。
- 利用者は自分1人。

## 2. 前提・方針
| 項目 | 決定内容 |
|---|---|
| 形態 | Webアプリ（PWA：ホーム画面に追加してアプリのように使える） |
| 対象端末 | スマホ中心（PCでも動作） |
| 記録の保存先 | 端末内（ブラウザ内ストレージ）。ログイン不要・サーバー不要 |
| バックアップ | 学習記録をファイルに書き出し／読み込みできる |
| 公開方法 | GitHub Pages（無料の静的サイト公開） |
| 単語データ | Claudeがオリジナルで作成（市販単語帳の転載はしない） |
| 初期収録数 | 300語 → 段階的に約2,500語まで拡充 |

## 3. 機能一覧（v1）

### 3.1 フラッシュカード＋間隔反復（SRS）
- カード表：英単語（＋発音ボタン）
- カード裏：品詞・日本語の意味・例文（英／日）
- 自己評価ボタン：**もう一度 / 難しい / 普通 / 簡単**
- 評価に応じて次回出題日を自動計算（SM-2 系アルゴリズム）
- 1日の流れ：「今日の復習（期限が来たカード）」＋「新規カード（既定 1日20語、設定で変更可）」
- 間隔の計算（`src/lib/srs.ts`）
  | 評価 | 初回 | 2回目 | 3回目以降 | 易しさ係数 |
  |---|---|---|---|---|
  | もう一度 | 今日中に再出題 | 同左 | 同左（連続正解リセット） | −0.20 |
  | 難しい | 1日 | 前回×1.2 | 前回×1.2 | −0.15 |
  | 普通 | 1日 | 3日 | 前回×係数 | ±0 |
  | 簡単 | 4日 | 7日 | 前回×係数×1.3 | ＋0.15 |
  - 易しさ係数の初期値 2.5、下限 1.3。間隔の上限 365日
  - 間隔 21日以上を「習得済み」とする
- 1日の上限を学び終えた後も「新しい単語をあと10語学ぶ」で追加学習できる
- PC ではキーボード操作可（スペース：答えを表示、1〜4：評価）

### 3.2 4択クイズ
- 出題形式：英→日／日→英 を選べる
- 誤答の選択肢は同じ品詞から選ぶ（簡単すぎる問題を避ける）
- 間違えた単語は SRS 側でも「もう一度」扱いにする（学習中の単語のみ。未学習の単語は記録しない。正解しても SRS の間隔は変えない）
- 出題範囲：学習した単語／すべて。問題数：10・20・30問
- 誤答の選択肢は表示文字が重複しないものを選び、同じ品詞が足りなければ他の品詞で補う
- 結果画面で正答率と間違えた単語を表示し、間違えた問題だけをやり直せる
- PC ではキーボード操作可（1〜4：回答、Enter／スペース：次へ）

### 3.3 音声読み上げ
- 単語・例文をタップで発音（ブラウザ内蔵の音声合成を使用、無料）
- 自動再生のON/OFF、読み上げ速度、アクセント（米・英・豪 など）を設定可能
  - TOEIC は米・英・カナダ・豪の発音が出題されるため
- スピーカーボタン：フラッシュカード（単語・例文）、クイズ（問題・解説）、単語一覧
- 自動発音：カード表示時／英→日クイズの問題表示時／日→英クイズの回答後
- 声の選択：アクセントの言語コードが一致する声（端末内蔵を優先）→ なければ他の英語の声で代用し、設定画面にその旨を表示
- 設定画面の「試しに聞く」で、アクセント・速度を確認できる

### 3.4 学習記録・進捗
- 今日の学習数、連続学習日数
- 習得状況の内訳（未学習 / 学習中 / 習得済み）
- 日別学習数のグラフ（直近30日）
- 苦手単語リスト（間違いが多い順）

### 3.5 単語一覧・検索
- 全単語の一覧、検索、カテゴリ／習得状況での絞り込み

## 4. 単語データの形式（案）
```json
{
  "id": "w0001",
  "word": "invoice",
  "pos": "noun",
  "meaning": "請求書",
  "example": "Please send the invoice by Friday.",
  "exampleJa": "金曜日までに請求書を送ってください。",
  "level": 600,
  "category": "finance"
}
```
- `level`：目安スコア帯（600 / 730 / 860）
- `category`：general（頻出一般語）、office（オフィス）、meeting（会議）、hr（人事・採用）、finance（財務・会計）、sales（営業・マーケ）、logistics（物流・製造）、travel（旅行・交通）、events（飲食・イベント）
- `pos`：noun / verb / adjective / adverb / preposition / conjunction / phrase
- データ本体は `src/data/words.json`。`npm run check:words` で必須項目・重複・値の妥当性を検査（ビルド時にも自動実行）

## 5. 技術構成（案）
| 役割 | 採用技術 |
|---|---|
| 画面を作る仕組み | React + TypeScript |
| 画面の切り替え | React Router（HashRouter） |
| 開発・ビルドツール | Vite |
| オフライン対応・ホーム画面追加 | vite-plugin-pwa |
| 記録の保存 | IndexedDB（学習記録）／ localStorage（設定） |
| 音声 | Web Speech API（speechSynthesis） |
| グラフ | 軽量なグラフライブラリ（Chart.js 等） |
| 公開 | GitHub Actions で自動ビルド → GitHub Pages |
